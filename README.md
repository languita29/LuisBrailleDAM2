## 📖 Descripción

Este repositorio contiene los ejercicios, prácticas y proyectos desarrollados a lo largo de **2º curso del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**.

Cada carpeta corresponde a uno de los módulos cursados este año, organizados de forma independiente para facilitar su consulta y mantenimiento.
